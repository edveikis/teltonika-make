# 🛠️ Build Systems

A collection of small, self-contained examples for learning **GNU Make**, **CMake**, and **GNU Autotools**.

## 📂 Structure

- **📄 Make and Makefiles** - Core GNU Make concepts, organized by topic:
  - Automatic variables, wildcards, and pattern-specific variables
  - Static and implicit pattern rules
  - Conditionals (`ifdef`, `ifeq`, etc.)
  - Built-in functions (`foreach`, `filter`, `call`, `shell`, `if`, string substitution)
  - Recursive `make` and environment/export behavior
  - Command echoing, shell selection, `.PHONY`, `.DELETE_ON_ERROR`, `vpath`
- **📦 CMake** - A simple project with a static library and executable built via CMake
- **⚙️ GNU Autotools** - A project configured with `autoconf`/`automake` (`configure.ac`, `Makefile.am`)
